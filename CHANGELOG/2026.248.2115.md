# 2026.248.2115 — fix(media): transcode reads the source from the op input + schema declares source_artifact

## Summary

RCA (live, check-instrument-cachyos-vm): the bed-runner evidence phase threads the entry's primary artifact as the pipeline source, but the transcode verb read source_artifact only from the check env — which is fixed at runner construction and cannot carry a per-entry path — so the pipeline failed with "no source artifact in the check env". The schema also rejected the threaded field (field not allowed).

- schema/transcode.cue + params: declare source_artifact (the HOST path of the source to transcode; the evidence phase threads the entry's primary artifact).
- provider: read the source from the op input first (source_artifact), the check env second (direct/plan-step dispatch fallback).
- provider: when the evidence phase's injected artifact (the shared validators' contract) IS the source, clear it so the output derives from the source instead of being rejected as a non-mp4 output path.
